# TecKits App 🚀

Welcome to the **TecKits App** project! This is a clean, minimal Flutter application that serves as the foundation for an upcoming mobile experience.

## ✨ Project Overview
The project is currently in its initial setup phase. It features a lightweight and optimized startup point utilizing a custom dark-green themed UI skeleton.

## 🛠️ Built With
- **[Flutter](https://flutter.dev/)**: The UI toolkit for natively compiled applications.
- **Dart**: The modern, object-oriented language that powers Flutter.

## 🚀 Getting Started
To run this project locally, ensure you have Flutter installed. Then run:
```bash
flutter pub get
flutter run
```
